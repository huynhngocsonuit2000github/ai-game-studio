# Asset provenance and approval

The asset files are made for this game from text prompts and original procedural drawing and sound synthesis. No downloaded character, music, stock photo, named franchise or third-party font binary is included. Consult the [asset manifest](ASSET_MANIFEST.csv) for exact paths and role. Generated art is under applicable [OpenAI output terms](https://openai.com/policies/terms-of-use/#using-our-services); use the game-specific import grant from the Producer and review images for unintended marks. Ordinary system typefaces are used for baked title and concept typography and are not distributed separately.

- Image generation sources: `key-illustration.png` uses a lantern cat and antlered owl in Bellgrave. `creature-sheet.png` uses nine coordinated actor/ward poses. `prop-sheet.png` uses nine environmental and pickup props. `ground-painting.png` uses low-contrast hand-painted slate without environmental objects.
- Runtime art: source images cropped, masked and resized to deployment dimensions. Frame bounds and tint specifications in JSON. Skill icons are original authored geometry drawn to raster. Cover, banner, card and key art derive from the same master with different crops.
- Runtime audio: original synthesis, composition and cues in `assets/source/audio-score.py`. No recorded samples. Use the existing WAV exports. The score is optional editable source for an authorized local workflow. Nothing in the archive requires executing it.
- Concept material: `assets/concept/combat-layout.webp` assembles the runtime sprites, textures and HUD plates as a target composition. Exclude it from gameplay distribution.
- Internal pack validation used synthetic external approval solely for offline schema verification. **Actual public-repo import approval exists only when the Producer submits the external paste prompt** referencing the verified archive digest and exact destinations. The ZIP's approval object declares the values that must match that separate decision to pass the Studio staging validator. Do not interpret archive contents as authorization. **Public Pages and G4 release decisions remain pending.**
