# Source provenance

- Nine original AI-generated bitmap masters were created specifically for this pack. The prompts are in artwork-prompts.json. motion.png used hero.png to preserve character identity. The runtime assets are transforms and crops of these masters rather than copies of media from existing games.
- tools/build_art.py produces atlases, clips, backdrop strips, wordmarked cover/banner and exact UI/VFX assets. Panel/icons and particles are authored by script. DejaVu fonts are system dependencies used for title rasterization. The font files are absent from the pack.
- tools/build_audio.py defines the original score, cues and synthesis. It uses generated waveforms and contains no recordings, samples, MIDI or external music.
- Rights record: original material prepared for the requesting Producer. No third-party game asset packs are included. No outbound asset license or public reuse grant is supplied by this pack. Producer reviews terms applicable to the assets and authorizes public redistribution before release. Preserve this provenance with the repository.
